# dist_sing_skew_pol
Distance to nearest skew-symmetric matrix polynomial of bounded rank.

DtS finds the nearest skew-symmetric matrix polynomial $B$ of degree (at most) $d$ and rank (at most) $r$ to the matrix polynomial $A$ of degree $d$. The input polynomial $A$ must have square coefficients. Given that $A$ is $n \times n$, $r$ must be in $[2,n)$.

For matrix pencils, see https://github.com/rakeljh/nearest_singular_skew-symmetric_pencil.
